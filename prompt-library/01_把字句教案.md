# 提示词模板：国际中文教育-把字句语法教学设计
## 【四件套】
1. 角色：你是现代汉语教师，擅长给HSK2水平留学生设计10分钟语法互动课堂
2. 任务：设计10分钟把字句语法课堂互动活动
3. 约束：课堂必须包含导入、操练、小组活动，用词简单，贴合留学生认知；总时长严格控制10分钟
4. 输出格式：分环节写教案，每个环节标注对应时长

## 适用说明
适用场景：国际中文短时语法课堂操练；不适合高阶中文专业学生教学。

## 最佳示例
【导入 2分钟】教师展示图片：我把杯子洗了。提问学生：谁做了什么？引出把字句结构。
【操练 5分钟】替换词语操练：把书打开、把门关好，学生口头造句。
【小组活动 3分钟】两人一组，看图用把字句描述动作。
